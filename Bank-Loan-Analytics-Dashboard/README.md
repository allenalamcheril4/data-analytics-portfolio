# Bank Loan Analytics Dashboard

## Overview
Interactive Power BI dashboard analyzing customer loan acceptance patterns and financial behavior.

## Tools Used
- Power BI
- Excel
- DAX

## Key Insights
- Higher income customers showed greater loan acceptance
- Online banking users were more likely to accept loans
- Education level influenced loan adoption
- Families with 3–4 members showed higher loan interest

## Dashboard Features
- KPI cards
- Loan acceptance analysis
- Customer segmentation
- Income distribution analysis
- Interactive slicers
