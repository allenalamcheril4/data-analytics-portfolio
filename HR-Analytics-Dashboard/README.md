# HR Analytics Dashboard

## Overview
Interactive Power BI dashboard analyzing employee attrition, departments, demographics, and workforce trends.

## Tools Used
- Power BI
- Excel
- DAX

## Key Insights
- Research & Development showed highest attrition
- Employees aged 25–35 had higher turnover
- Work-life balance influenced employee retention
- Sales roles had significant attrition trends

## Dashboard Features
- KPI cards
- Interactive slicers
- Department analysis
- Employee demographics
- Attrition trend analysis
