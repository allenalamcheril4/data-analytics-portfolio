# Sales Dashboard

## Overview
Interactive Power BI dashboard analyzing sales performance, revenue trends, and business insights.

## Tools Used
- Power BI
- Excel
- DAX

## Key Insights
- Identified high-performing product categories
- Regional sales trends revealed key growth areas
- Seasonal revenue patterns impacted sales performance

## Dashboard Features
- KPI cards
- Revenue analysis
- Sales trend tracking
- Regional performance analysis
- Interactive filtering
